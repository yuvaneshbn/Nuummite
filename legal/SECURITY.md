# Security Policy

## Supported Versions

Security fixes are expected to be applied to the main development branch and to
any release branches that are actively maintained.

## Reporting a Vulnerability

If you discover a security issue, please do not open a public issue.

Report it privately to `security@nuummite.example` with:

- a short summary of the issue
- affected component or feature
- steps to reproduce, if available
- any proof of concept or logs that help explain the impact

## What to Include

- Environment details
- Affected version or commit
- Whether the issue affects confidentiality, integrity, or availability
- Suggested mitigation, if you have one

## Response Process

We will review the report, confirm the issue, and coordinate a fix before any
public disclosure.

## Disclosure Request

Please allow reasonable time for triage and remediation before public
discussion of the issue.
